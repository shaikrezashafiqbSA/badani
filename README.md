# Badani Journal

Static workout journal (no build, no backend). Data is stored in the browser's localStorage; use Settings → Export to back up.

## Deploy on GitHub Pages
1. Push `index.html`, `style.css`, `app.js` to a repo.
2. Repo Settings → Pages → Deploy from branch → `main` / root.

## Local preview
`python -m http.server 8765` then open http://localhost:8765
